# 육아·아기 사진 앱 벤치마크 (2026-11-21)

베베컵에 무엇을 더 넣을지 정하기 위해 국내외 육아·아기 사진 앱을 조사했다. 근거는 주로 App Store 상세 페이지(한국·미국), 공식 블로그, 2025–2026년 기사다. 스토어 리뷰는 화면에 보이는 일부만 봤으므로 불만 항목은 참고 수준이다. 확인하지 못한 것은 "미확인"으로 적었다.

## 1. 한 줄 결론

- **가족이 토너먼트로 사진을 고르는 앱은 찾지 못했다.** AI 베스트 컷 선별은 스냅스·Bebememo가 이미 하지만 모두 서버 업로드가 전제다. "기기 안에서 고르고, 가족이 월드컵으로 정한다"는 조합은 비어 있는 자리다.
- 경쟁 앱이 사람을 다시 오게 만드는 장치는 **① 아이 나이(월령) 기준 정리 ② 매달·매년 자동으로 나오는 결과물(월간 포토북, 1초 영상, 연말 리캡) ③ 가족 반응**이다. 베베컵은 ③은 원칙상(서버 필요) 못 하고, ①②가 비어 있다.
- 그래서 우선순위는 **아기 프로필(생일) → 월령 라벨 → "이달의 월드컵" → "올해의 월드컵(연말 리캡)"** 순서로, 지금의 넛지 → 정리 → 월드컵 → 인화 여정에 **월·연 주기**를 입히는 것이다.

## 3. 베베컵에 넣을 후보

판정 기준은 AGENTS.md 원칙(실제 사용자 사진만, 외부 업로드 없음, 분석·광고·추적 SDK 없음, 인화는 사용자가 여는 handoff까지)이다.

## 4. 효과를 어떻게 볼 것인가

베베컵은 분석 SDK를 넣지 않으므로 앱 안 지표를 모을 수 없다. 대신:

- Play Console 통계(설치·삭제·유지)와 Alpha 테스터 의견으로 본다.
- 1순위를 넣은 뒤 테스터에게 묻는다: "이달의 월드컵 알림을 받고 실제로 정리·월드컵까지 했는지", "월령 라벨이 인화할 사진을 고를 때 도움이 됐는지".
- 반응이 없으면 2·3순위로 가기 전에 여정 자체를 다시 본다.
