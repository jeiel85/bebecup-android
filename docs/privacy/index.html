베베컵 개인정보처리방침

최종 업데이트: 2026-11-22

1. 서비스

베베컵은 부모 또는 보호자가 직접 선택한 로컬 아기 사진으로 이상형 월드컵을 만들고 인화 후보를 정리하는 Android 앱입니다.

2. 처리하는 정보

앱은 사용자가 Android Photo Picker에서 직접 선택한 사진의 로컬 URI와 앱 사용 중 생성한 후보/월드컵 기록을 기기 내부 저장소에 저장합니다. 사용자가 사진 접근을 허용하고 사진 정리를 시작하면, 기간 안의 최근 사진을 기기 안에서 읽어 흔들림·노출·얼굴·눈 뜸·표정을 분석하고 그 점수를 기기 내부 저장소에 저장합니다. 사용자가 원해서 입력한 경우 아기 이름(또는 태명)과 생일도 기기 내부 저장소에 저장하며, 사진이 아기가 몇 개월 때 찍은 것인지 계산해 보여 주는 데만 씁니다.

3. 수집 및 공유

베베컵은 사진 파일, 사진 URI, 사진 분석·얼굴 인식 결과, 아기 정보, 위치 정보, 연락처, 계정 정보를 외부 서버로 보내거나 제3자와 공유하지 않습니다. 광고·분석·추적 SDK를 넣지 않습니다.

얼굴 인식에는 Google ML Kit을 씁니다. 얼굴 인식은 기기 안에서만 이뤄지지만, ML Kit은 기능의 성능과 사용에 관한 지표(기기 제조사·모델, Android 버전, 앱 패키지 이름·버전, 처리 시간, 이벤트 종류, 오류 코드, 설치마다 만들어지는 식별자)를 Google에 보낼 수 있습니다. 사진, 얼굴 데이터, 인식 결과는 보내지 않습니다. 이 전송은 앱에서 끌 수 없습니다. 자세한 내용은 Google의 ML Kit 약관과 Android 데이터 공개 안내에 있습니다.

Google Play에서 설치한 앱은 얼굴 인식 모델을 처음 쓸 때 Google Play 서비스가 내려받습니다. 이때도 사진은 기기 밖으로 나가지 않습니다. GitHub에서 받은 APK는 모델이 앱 안에 들어 있습니다.

Google Play에서 설치한 앱은 새 버전이 있는지 기기의 Google Play 앱에 묻습니다(Play 인앱 업데이트). 이 확인과 업데이트 설치는 Google Play가 처리합니다.

GitHub에서 받은 APK는 새 버전이 있는지 확인하려고 앱을 열 때(몇 시간에 한 번)와 설정에서 '업데이트 확인'을 누를 때 GitHub 릴리스의 버전 정보 파일(update.json)을 받고, 사용자가 업데이트를 누를 때만 새 APK를 받습니다. 이 요청에는 사진·기록·기기 식별자가 담기지 않으며, 접속 IP 같은 통신 기록은 GitHub의 정책에 따라 처리됩니다.

4. 외부 인화 사이트

앱은 사용자가 명시적으로 선택한 경우 외부 인화 사이트를 브라우저로 열 수 있습니다. 이 경우 이후의 개인정보 처리와 주문 절차는 해당 외부 사이트의 정책을 따릅니다. 베베컵은 사진 파일을 외부 인화 사이트에 자동 업로드하지 않습니다.

5. 보관 및 삭제

사진 후보와 기록은 사용자의 기기에만 저장됩니다. 사용자는 앱 안에서 후보를 삭제하거나 Android 설정에서 앱 데이터를 삭제할 수 있으며, 앱을 삭제하면 로컬 데이터도 함께 삭제됩니다. 아기 정보는 앱 설정에서 언제든 지울 수 있습니다. 휴대폰에서 Google 백업을 켜 둔 경우 Android가 앱 데이터를 사용자 본인의 Google 계정 백업에 포함할 수 있습니다.

6. 보안

앱 데이터는 Android 앱 샌드박스 안에 저장됩니다. 베베컵이 직접 외부로 보내는 데이터는 없습니다. 3항의 ML Kit 지표는 Google이 보내고 처리합니다.

7. 어린이 데이터

베베컵은 어린이를 대상으로 제작된 앱이 아니며, 18세 이상의 부모 및 보호자가 사용하도록 설계되었습니다. 앱은 어린이로부터 어떠한 개인정보도 직접 수집하지 않습니다.

8. 정책 변경

본 방침이 변경되는 경우 본 페이지를 통해 공지합니다. 중요한 변경은 최종 업데이트 일자로 표시됩니다.

Bebecup Privacy Policy

Last updated: 2026-11-22

1. Service

Bebecup is an Android app that lets parents and guardians build a photo tournament from local baby photos they personally choose, and organize favorite photos for printing.

2. Information processed

The app stores, on the device only, the local URIs of photos the user explicitly selects through the Android Photo Picker, together with the tournament and candidate records the user creates while using the app. When the user allows photo access and starts sorting, the app reads recent photos from the chosen period on the device, analyzes blur, exposure, faces, open eyes and expressions there, and stores those scores on the device only. If the user chooses to enter them, the baby's name (or nickname) and birthday are also stored on the device only, and are used only to show how old the baby was in each photo.

3. Collection and sharing

Bebecup does not send photo files, photo URIs, photo analysis or face detection results, the baby's details, location, contacts, or account information to any external server, and does not share them with third parties. No advertising, analytics, or tracking SDKs are included.

Face detection uses Google ML Kit. Detection runs entirely on the device, but ML Kit may send Google metrics about the feature's performance and use (device maker and model, Android version, app package name and version, processing time, event type, error codes, and a per-installation identifier). It does not send photos, face data, or detection results. The app cannot turn this off. See Google's ML Kit terms and Android data disclosure.

When installed from Google Play, the face detection model is downloaded by Google Play services the first time it is needed; photos stay on the device. The APK from GitHub includes the model.

The APK from GitHub checks for a new version by downloading a version file (update.json) from GitHub Releases when the app opens (at most every few hours) and when you tap Check for updates in Settings, and downloads a new APK only when you choose to update. These requests carry no photos, records or device identifiers; connection data such as your IP address is handled under GitHub's own policies.

When installed from Google Play, the app asks the Google Play app on the device whether a newer version is available (Play In-App Updates). Google Play handles that check and any update.

4. External print sites

The app may open external print sites in the user's browser when the user explicitly chooses to do so. Any subsequent data processing and ordering on those sites is governed by the policies of those external services. Bebecup does not automatically upload photo files to external print sites.

5. Retention and deletion

Photo candidates and records are stored only on the user's device. The user can delete candidates from inside the app, clear app data from Android system settings, or uninstall the app, which also removes the local data. The baby's details can be cleared at any time in the app's settings. If Google backup is turned on for the phone, Android may include app data in the user's own Google account backup.

6. Security

App data is stored inside the Android app sandbox. Bebecup itself sends no data off the device; the ML Kit metrics in section 3 are sent and processed by Google.

7. Children's data

Bebecup is not designed for children. It is intended for use by parents and guardians aged 18 or older. The app does not directly collect any personal information from children.

8. Changes to this policy

Changes to this policy will be communicated through this page. Material changes will be reflected in the "Last updated" date above.
